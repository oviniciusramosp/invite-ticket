# Coquetel Paradigma — Invite Ticket

Ticket holográfico interativo (golden / orange) com flip 3D e efeito Amazing Rare.

## Demo

Publicado via GitHub Pages após o deploy.

## Local

```bash
python3 -m http.server 8765
```

Abra `http://localhost:8765`.

## Interação

- Mover o cursor → tilt 3D + foil holo
- Clique no ticket → vira frente/verso
- Botão **Golden / Orange** → troca a variante

Efeito inspirado em [simeydotme/pokemon-cards-css](https://github.com/simeydotme/pokemon-cards-css).
